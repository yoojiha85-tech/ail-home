기준 자료: 「2026~2027 하와이 호텔 리스트 26.10.07 (21차)」 엑셀 + 자동견적 산출 공식(전달받은 HTML 수정본 계산 로직 요약본)

## 1. 페이지 사용자와 노출 규칙

전달해주신 안내문에는 **목표수익(마크업)이 그대로 들어 있어 직원용 문서**입니다. 그래서 같은 페이지를 **권한별로 다르게 보여주는 구조**를 제안합니다.

| 항목 | 직원용(관리자 로그인) | 고객용(링크 공유) |
|---|---|---|
| 최종 1인 / 2인 판매가 | ✅ | ✅ |
| 공식 풀이(USD × 환율 + 원화) | ✅ 전체 | ✅ 간단 3단계 설명 |
| 호텔 객실비 USD / 환율 | ✅ | ⚠️ 환율은 "적용 환율 기준일"만 표시 |
| 지상비·가이드팁·작가팁 | ✅ 금액 | ✅ "포함/현지 지불" 구분으로만 표시 |
| 사은품·보험 | ✅ 금액 | ✅ 혜택 이름만 (원가 금액 ❌) |
| **마크업 750,000원** | ✅ | ❌ **절대 비노출** |
| 할인 | ✅ | ✅ "특별 할인 −○○원" |
| 21차 요금 적용 원칙·제외 조건 | ✅ | ❌ (내부 검수 기준) |

> 구현 시 주의: 고객용 화면은 "숨김(CSS)"이 아니라 **데이터 자체를 보내지 않는 방식**이어야 합니다. 브라우저에서 소스 보기를 하면 마크업이 보이는 사고를 막기 위해서입니다. (Supabase 사용 시 고객 조회용 뷰와 관리자용 테이블 분리 + RLS)

## 3. 섹션별 상세 기획

### ① 상단 요약 배너
- 제목: **하와이 허니문 요금 계산 안내**
- 뱃지: `요금표 21차 · 2026.10.07 기준` / `환율 1,521원/USD` / `성인 2인 기준`
- 우측 상단 **[직원용 / 고객용] 전환 토글** (직원 로그인 상태에서만 노출)

### ② 핵심 공식 카드
- 공식 한 줄을 가장 크게, 색을 구분해 표시
  - 달러 부분 = **파란색** / 원화 부분 = **초록색** / 할인 = **빨간색**
- 카드 아래 한 줄 설명: *"달러로 정해진 현지 비용에만 환율을 곱하고, 한국에서 원화로 결제되는 비용은 그대로 더합니다."*
- 여행업 비유: "해외 호텔·현지 비용은 달러 영수증, 항공·보험은 원화 영수증으로 따로 계산해서 마지막에 합친다."

### ③ 3단계 흐름도 (모바일은 세로 카드)
| 단계 | 하는 일 | 예시 |
|---|---|---|
| **1단계 달러 합산** | 객실비(1인분) + 지상비 + 팁 등 | $500 + $210 = **$710** |
| **2단계 환율 곱하기** | 달러 합계 × 적용 환율 | $710 × 1,521 = **1,079,910원** |
| **3단계 원화 더하고 할인 빼기** | + 항공 + 마크업·사은품·보험 − 할인 → 1,000원 단위 반올림 | **3,872,000원** |

### ④ 항목별 상세표 — "달러 항목"과 "원화 항목"을 **두 칸으로 분리**
기존 표는 14개 항목이 한 줄로 섞여 있어 어떤 항목에 환율이 곱해지는지 헷갈립니다. 아래처럼 나누면 한눈에 구분됩니다.

**A. 달러(USD) 항목 → 환율 곱함**
| 항목 | 기준 | 계산 방식 |
|---|---|---|
| 호텔 객실비 | 1인 | 숙박일별 객실 USD 요금 합계 ÷ 성인 인원 |
| 조식 추가비 | 1인 | 조식 불포함 객실에서 추가 신청한 경우만 |
| 호텔 별도비용 | 1인 | 요금에 포함되지 않은 부대비용(예: 마우이 하얏트 포터리지 1인 $18) |
| 지상비 | 1인 | 현지 행사·차량 등 |
| 가이드팁 | 1인 | |
| 작가팁 | 1인 | 스냅 촬영 작가 매너팁 |
| 기타 현지비용 | 1인 | 사용자 직접 입력 |

**B. 원화(KRW) 항목 → 환율 곱하지 않음**
| 항목 | 기준 |
|---|---|
| 국제선 항공 | 1인 |
| 이웃섬 주내선 | 1인 (이웃섬 포함 일정만) |
| 사은품 | 1인 |
| 여행자보험 | 1인 |
| 마크업(구 목표수익) | 1인 (**직원용만**) |
| **할인** | 최종 판매가에서 차감 |

### ⑤ 기본 입력값 카드 (현재 HTML 기본값)
| 카드 | 값 | 설명 |
|---|---|---|
| 국제선 항공 / 1인 | **1,981,700원** | 원화 |
| 적용 환율 | **1,521원/USD** | 직접 입력값, 기준일 함께 표기 |
| 지상비 + 가이드팁 + 작가팁 | **$210** | 스마트 플러스 $150 + 가이드팁 $30 + 작가팁 $30 (엑셀 일정표와 일치 ✅) |
| 마크업 + 사은품 + 여행자보험 | **810,000원** (마크업 750,000 + 허니문 사은품 50,000 + 보험 10,000) | 마크업·사은품 금액은 직원용만 표시, 고객용은 "허니문 혜택·여행자보험 포함"으로 대체 |

### ⑥ 실시간 계산기 (이 페이지의 핵심)
**입력 5칸**
1. 호텔 총 객실비 (USD / 2인)
2. 환율 (원/USD)
3. 국제선 항공 (원/1인)
4. 마크업 (원/1인) — 직원용만 (기본 750,000)
5. 할인 (원/1인)

**결과 4칸 (자동 계산)**
1. 현지비용 / 1인 (USD)
2. 현지비용 원화환산
3. **최종 1인 판매가** (가장 크게)
4. **2인 총 판매가**

UI 규칙
- 입력칸 아래에 **"이 값은 어디서 나온 숫자인가요?"** 짧은 도움말 (예: 호텔 총 객실비 = 요금표 1박 요금 × 박수)
- 숫자 입력 시 천 단위 콤마 자동 표시, 음수·빈칸 방지
- 결과 영역은 모바일에서도 입력칸 바로 아래에 붙여서 **스크롤 없이 결과 확인**
- **[초기값으로 되돌리기]**, **[견적서로 보내기]** 버튼 (2단계)

### ⑦ 계산 예시 (단계별 풀이)
엑셀·전달 자료의 예시를 **검산한 결과 모두 일치**합니다.

| 단계 | 계산 | 결과 |
|---|---|---|
| 호텔 객실비 1인 | $1,000(2인 총액) ÷ 2명 | $500 |
| + 지상비·팁 | $500 + $210 | **$710** |
| 환율 적용 | $710 × 1,521 | **1,079,910원** |
| + 항공 + 마크업·사은품·보험 | 1,079,910 + 1,981,700 + 810,000 = 3,871,610 | 3,871,610원 |
| 1,000원 단위 반올림 | 백원 자리 5 이상 올림 | **3,872,000원 (1인)** |
| 2인 합계 | 3,872,000 × 2 | **7,744,000원** |

> 위 예시에서 호텔 총 객실비는 **$1,000으로 역산한 값**입니다(현지비용 $710 − $210 = $500 × 2명). 원본 HTML 입력값과 대조 ⚠️ **확인 필요**.

**추가 예시 카드 (2개 권장)**
| 예시 | 계산 포인트 | 결과(참고) |
|---|---|---|
| 오아후 · 쉐라톤 와이키키 4박, City View (2026 SW LTO, 조식 불포함) | 1박 $410 × 4박 = $1,640 ÷ 2 = $820 → +$210 = $1,030 → ×1,521 = 1,566,630원 → + 1,981,700 + 810,000 = 4,358,330 → 반올림 | **4,358,000원 / 1인** |
| 마우이 하얏트 | 호텔 별도비용 **포터리지 $18/인**을 반드시 달러 항목에 추가 | 별도 입력 필요 |

※ 위 쉐라톤 예시는 설명용이며, 실제 판매 전 예약기간·최소 숙박·프로모션 조건 확인이 필요합니다.

### ⑧ 21차 요금 적용 시 주의사항 (직원용)
전달받은 원칙을 **체크리스트 카드 4개**로 구성하고, 엑셀에서 확인된 실제 사례를 함께 보여줍니다.

| 원칙 | 엑셀에서 확인된 실제 사례 |
|---|---|
| 세금·리조트피는 이미 포함 → **중복 가산 금지** | 요금표에 "리조트피 ㅇ(포함)" 표시. 마우이 하얏트는 "리조트피 포함"이지만 **포터리지 $18/인은 별도** |
| 조식은 **원본 요금표의 포함/불포함 조건대로** | 같은 쉐라톤 와이키키 안에서도 "1박/조식불포함"과 "1박/조식포함" 표가 섞여 있음. 와이키키리조트(3성)는 컨티넨탈 조식 포함 |
| 무료숙박 프로모션은 **조건 확정 시에만** 객실비에서 차감 | "4박 예약시 업그레이드", "5박 이상 ROO 업그레이드", "신규 예약자에 한함" 등 조건부 프로모션 다수 |
| **예약기간·최소숙박·Blackout·프로모션 우선순위 미확정 요금은 자동견적 제외** | 쉐라톤 와이키키 Black-out `7/6~7/9, 7/22~7/26`, 마우이 하얏트 **미니멈 2박** |

## 5. UI 개선 제안 (현재 문제 → 수정 방법 → 기대 효과)

| 현재 문제 | 수정 방법 | 기대 효과 |

| 계산 예시가 결과만 보임 | **단계별 풀이 표**(① 객실비 → ② 달러합 → ③ 원화환산 → ④ 합계) | 고객에게 설명할 때 그대로 화면 공유 가능 |

| 21차 요금 조건이 글로만 존재 | **체크리스트 카드 + 위험도 뱃지** | 미확정 요금이 자동견적에 들어가는 실수 방지 |
| 모바일에서 표가 깨질 위험 | 표는 모바일에서 **카드 목록으로 변환**, 결과 금액은 하단 고정 바 | 이동 중에도 상담 가능 |

## 6. 데이터 구조 (Supabase 연동 시)

엑셀 비유: **시트 5개를 고유번호로 연결**하는 구조입니다.

| 표(Table) | 엑셀로 비유하면 | 핵심 항목 |
|---|---|---|
| `fx_rates` | 환율 시트 | 통화, 적용환율, 기준일, 적용시작/종료 |
| `hawaii_hotels` | 호텔 리스트 시트 | 호텔ID, 공식명, 별칭, 섬(오아후/마우이/빅아일랜드), 등급 |
| `hawaii_room_rates` | 요금표 시트 | 호텔ID, 객실타입, 시작일, 종료일, 1박 USD, 조식포함 여부, 리조트피 포함 여부, 최소숙박, 블랙아웃, 예약가능기간(Booking Window), **차수(21차)**, **자동견적 사용 가능 여부** |
| `hawaii_extra_fees` | 부대비용 시트 | 호텔ID, 항목(포터리지·카할라 픽업 등), 금액 USD, 1인/1객실 구분 |
| `quote_cost_items` | 견적 원가 시트 | 견적ID, 항목명, 통화(USD/KRW), 금액, 기준(1인), **고객 노출 여부** |

핵심 장치 3가지
1. **UPSERT**: 차수가 바뀌어도(22차, 23차) 같은 호텔·객실·기간은 덮어쓰고 중복 생성 방지
2. **`is_auto_quote_ok` 플래그**: 조건이 미확정인 요금은 자동견적에서 제외
3. **견적 스냅샷 저장**: 발송한 견적은 당시 환율·요금을 복사 저장해서, 나중에 환율이 바뀌어도 고객에게 보낸 금액이 달라지지 않게 함 (ERP 기획서 방침과 동일)

## 9. 2단계 구현 현황 (요금표 자동 불러오기)

| 구성 | 파일 | 내용 |
|---|---|---|
| 변환 도구 | `tools/build_hawaii_rates.py` | 엑셀 요금표(차수별) → 데이터 파일로 변환. 22차가 나오면 같은 명령으로 갱신 |
| 요금 데이터 | `data/hawaii-rates-21.js` | 45개 호텔 / 956개 객실요금. 자동 생성 파일이라 직접 수정 금지 |
| 직원용 화면 | `hawaii-price-guide.html` | 지역 → 호텔 → 프로그램 → 객실 → 체크인·박수 선택 시 박별 요금을 합산해 "호텔 총 객실비"에 적용 |

**안전장치**
- 예약가능기간(Booking Window) 종료·시작 전 프로그램은 적용 불가 (예: 쉐라톤 SEPTEMBER SPECIAL)
- 최소숙박 미달, 날짜에 해당 요금이 없는 박이 있으면 적용 불가
- 프로모션·Blackout·콤보·신규예약자 등 **조건부 요금은 직원이 확인 체크를 해야 적용**
- 연도 오타 등 날짜가 이상한 요금 행은 자동 제외 (쉐라톤 `08/16/06`, 칼라이 `…/2028`, 애스턴 `08/152026` 등 15건)
- 포터리지 등 의무 부대비용(1인 $18~$24)은 체크 시 "호텔 별도비용"에 자동 반영
- 요금이 없는 호텔(일리카이, 할레푸나, 할레쿨라니, 안다즈 마우이 등)은 "별도 문의"로 안내

**확인 필요:** 요금표에 인원 조건(예: 리츠칼튼 3~4인 객실)이 있는 호텔, 쉐라톤 마우이 등 "A --> B 업그레이드" 요금은 객실명 그대로 표시되므로 담당자가 판매 조건을 확인해야 합니다.
