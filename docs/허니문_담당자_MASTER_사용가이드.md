# 허니문 담당자용 MASTER 화면 사용 안내서

> 대상: 허니문 상담·예약 담당 직원
> 목적: 구글시트 입력을 새 화면(MASTER, ops.honeytrip.co.kr) 입력으로 전환
> 최종 업데이트: 2026-09-21

## 왜 새 화면으로 옮겨야 하나요?

- 구글시트와 MASTER 화면은 **양방향으로 자동 동기화**되어 있어 데이터가 사라지지 않습니다.
- 하지만 두 군데에 나눠서 입력하면 **오탈자·중복 입력·엇갈림 사고**가 생기기 쉽습니다.
- MASTER 화면은 견적·계약·체크리스트·정산이 **한 화면에서 연결**되어 있어, 시트보다 빠르고 실수가 적습니다.

## 기본 흐름 (전화·방문 상담 기준)

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 1 | 좌측 메뉴 **☎ 상담기록** | `+ 오프라인 상담 등록` 클릭 → 고객명·연락처·희망여행지·상담유형 입력 → 저장 |
| 2 | 상담기록 목록 | 상담 진행하며 상태를 신규→상담중→견적발송으로 변경 |
| 3 | 상담 상세 | 상담 완료되면 `예약으로 전환` 클릭 → 예약이 자동 생성됨 |
| 4 | 예약 상세 → **견적** 탭 | 견적서 작성·버전관리 |
| 5 | 예약 상세 → **계약** 탭 | 계약금액 확정, 서명 처리 |
| 6 | 예약 상세 → **입금·환불** 탭 | 계약금·중도금·잔금 입금 등록 |
| 7 | 예약 상세 → **지출·송금** 탭 | 랜드사 송금 등록 |
| 8 | 예약 상세 → **출발 체크** 탭 | 여권사본·최종체크 등 출발 전 필수 확인 |

## 상담기록 화면에서 눈에 익혀둘 것

- **빨간 배지(신규)**가 24시간 넘도록 남아있으면 화면 상단에 "24시간 초과 미응대" 경고로 뜹니다 — 이 숫자가 0이 되도록 관리하는 게 목표입니다.
- 목록은 **미응대 건이 자동으로 맨 위**에 정렬됩니다. 위에서부터 처리하면 됩니다.
- 접수경로 필터로 온라인/전화/방문/소개 문의를 구분해서 볼 수 있습니다.

## 자주 헷갈리는 부분

| 상황 | 어떻게 하나요? |
|---|---|
| 상담상태를 바꿨는데 저장 버튼이 없다 | 상태 선택(드롭다운)은 **바꾸는 즉시 자동 저장**됩니다. 별도 저장 불필요. |
| 이미 예약으로 전환된 상담을 삭제하고 싶다 | 삭제 불가 — 예약이 연결된 상담은 보호됩니다. 예약 쪽에서 상태를 변경하세요. |
| 구글시트에도 입력했는데 화면에 안 보인다 | 동기화에 몇 초~1분 정도 걸릴 수 있습니다. 새로고침 후에도 안 보이면 관리자에게 알려주세요. |
| 중간항공(유럽 등 경유) 중도금 관리는 어디서? | 예약 수정 화면의 "중간 이동구간 항공" 섹션에서 체크·안내일 관리 |

## 문제가 생기면

1. 화면을 새로고침해도 안 되면 → 담당자(관리자)에게 캡처와 함께 전달
2. "permission denied" 같은 오류 메시지가 뜨면 → 즉시 캡처해서 전달 (권한 설정 문제일 수 있음)
3. 구글시트와 화면 값이 서로 다르면 → 입력 시각이 최근인 쪽이 반영된 것이므로, 최종 확정 값을 다시 한쪽에 입력해 맞춰주세요.
