# 허니문 담당자 실사용 테스트 체크리스트

> 대상: 허니문 상담·예약 담당 직원
> 목적: MASTER 화면(ops.honeytrip.co.kr)이 실제 상담 업무에서 문제없이 쓰이는지 검증
> 참고 문서: `허니문_담당자_MASTER_사용가이드.md`
> 진행 방법: 실제 고객 상담 1~2건을 처음부터 끝까지 이 화면으로만 진행해보고, 아래 항목에 체크

## 1단계 — 로그인 · 진입

- [ ] 본인 계정으로 로그인이 잘 되는가
- [ ] 로그인 후 본인 권한(상담 등록/수정/삭제 등)이 예상과 맞는가
- [ ] 좌측 메뉴에서 "☎ 상담기록" 메뉴가 보이는가

## 2단계 — 상담기록 등록 (오프라인 상담 기준)

- [ ] `+ 오프라인 상담 등록` 버튼이 눈에 잘 띄는가
- [ ] 고객명·연락처·희망여행지 등 필수 항목 입력이 헷갈리지 않는가
- [ ] 개인정보 수집·이용 동의 체크 없이 저장하면 안내 문구가 뜨는가
- [ ] 저장 후 목록에 바로 나타나는가

## 3단계 — 상담 진행 관리

- [ ] 상담상태(신규→상담중→견적발송 등) 변경이 직관적인가
- [ ] 상태 변경이 별도 저장 없이 바로 반영되는지 헷갈리지 않는가
- [ ] 목록 상단 요약(진행중/신규/오늘 접수/24시간 초과 미응대) 숫자가 실제 업무량과 맞게 느껴지는가
- [ ] 접수경로 필터(전화/방문/온라인 등)가 실제로 유용한가

## 4단계 — 예약 전환

- [ ] 상담을 예약으로 전환할 때 확인 메시지가 명확한가
- [ ] 전환 후 예약 상세 화면이 바로 열리는가
- [ ] 전환된 예약의 고객정보·여행지 등이 상담 내용과 일치하는가

## 5단계 — 견적 · 계약 · 입금

- [ ] 견적서 작성이 기존에 쓰던 방식(수기/엑셀 등)보다 편한가 불편한가
- [ ] 계약금액 확정 후 계약 탭에 정확히 반영되는가
- [ ] 입금 등록(계약금/중도금/잔금) 시 금액 계산이 맞는가

## 6단계 — 출발 전 체크리스트

- [ ] 여권사본·최종체크 등 항목이 실제 업무 순서와 맞는가
- [ ] 완료 처리 버튼을 눌렀을 때 반영이 즉시 되는가
