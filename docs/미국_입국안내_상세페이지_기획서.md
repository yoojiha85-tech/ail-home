# 미국 입국 안내 상세페이지 기획서

> 작성일: 2026-11-18 / 대상: (주)아일항공여행사 허니문 고객 + 상담 직원
> 목적: "미국 입국이 걱정되는 신혼부부"가 **출발 전 스스로 준비하고, 공항에서 당황하지 않도록** 돕는 고객용 안내 페이지

| 항목 | 내용 |
|---|---|
| 페이지 이름 | 「미국 입국, 이것만 알면 쉬워요」 (가칭) |
| 주 사용처 | 하와이·괌·미국 경유(칸쿤·캐리비안 등) 허니문 계약 고객 / 상담 중 링크 발송 |
| 핵심 목표 | ① 출발 전 준비(ESTA 등) 누락 0건 ② 입국심사 불안 해소 ③ 상담 직원 반복 설명 시간 절감 |

## 1. 고객이 가장 궁금해하는 것 (페이지 설계의 기준)

1. ESTA 꼭 해야 하나요? 언제, 얼마예요?
2. 공항에서 뭘 물어보나요? 영어를 못하는데 괜찮을까요?
3. 신혼여행이라고 하면 뭐 특별히 달라지나요?
4. 가져가면 안 되는 음식·약이 있나요?
5. 경유(환승)만 해도 ESTA가 필요한가요?
6. 줄이 너무 길면 어떡하죠? 연결편을 놓치면요?

→ 이 6가지를 **페이지 상단에서 3클릭 이내** 답을 찾게 만든다.

## 2. 페이지 구조 (위에서 아래 순서)

### ① 히어로 영역
- 문구: "공항에서 5분, 미리 알면 훨씬 편안한 입국"
- 버튼 2개: [입국 순서 바로보기] [출발 전 체크리스트]
- 하단 고정 메뉴(스티키): 준비 · 입국순서 · 심사 질문 · 세관 · 경유 · FAQ

### ② 30초 요약 카드 (핵심 5가지)
| 아이콘 | 핵심 |
|---|---|
| 🛂 | 여권 유효기간 · 전자여권 확인 |
| 📝 | **ESTA** 사전 승인 (출발 전 필수) |
| 🧾 | 돌아오는 항공권 · 숙소 주소 준비 |
| 🍎 | 과일·육류·씨앗류 반입 주의 |
| 📱 | 휴대폰 사진 저장 (ESTA 승인서·예약확인서) |

### ③ 출발 전 준비 타임라인 (스텝 카드)
| 시기 | 할 일 |
|---|---|
| 출발 30일 전 | 여권 유효기간 확인, ESTA 신청(여유 있게) |
| 출발 7일 전 | ESTA 승인 재확인, 항공 e-티켓·숙소 바우처 저장 |
| 출발 3일 전 | 상비약(영문 처방 안내), 보조배터리 규정 확인 |
| 출발 당일 | 여권·ESTA 승인 화면·숙소 주소 캡처 확인 |

### ④ ESTA 상세 카드
- 무엇인가: 비자 없이 미국에 가는 한국 여행객을 위한 **온라인 사전 여행허가**
- 어디서 신청: **미국 국토안보부 공식 사이트에서만** (사칭·대행 사이트 주의 경고 박스)
- 비용/유효기간/체류가능일: 아래 [확인 필요] 참조 후 기재
- 신청 시 준비물: 전자여권, 이메일, 카드, 미국 내 첫 숙소 주소
- 주의: 이름·여권번호 오타 = 입국 거절 사유 → "신청 후 반드시 승인서 PDF/캡처 저장"
- 허니문 특화: 신랑·신부 **각자 개별 신청** (한 명이 대리 신청해도 각자 여권 정보로 따로)

### ⑤ ★ 입국 순서 (핵심 섹션 — 7단계 스텝퍼)
| 단계 | 장소 | 해야 할 일 | 고객용 한 줄 팁 |
|---|---|---|---|
| 1 | 기내 | 세관신고서 작성(필요 시) | 부부가 같이 사는 경우 1장으로 가능한지 승무원에게 확인 |
| 2 | 도착 | "Arrivals / Immigration" 표지판 따라 이동 | 환승객은 "Connecting Flights" 표지 확인 |
| 3 | 입국심사 | 여권 제출 → 사진·지문 → 질문 | 신랑신부 **함께** 같은 창구로 |
| 4 | 수하물 | 수하물 수취 | 전광판에서 항공편명으로 벨트 확인 |
| 5 | 세관 | 신고서 제출 / 전자신고 | 해당 없으면 "Nothing to declare" |
| 6 | 환승객 | 짐 다시 부치기(Re-check) | 경유 공항은 보안검색을 다시 거침 |
| 7 | 출구 | 픽업 / 택시 / 렌터카 | 미팅 장소를 미리 캡처 |

※ 공항별로 키오스크(자동입국심사), 전자신고 시스템이 달라 **"공항별 차이는 현장 안내판 우선"** 문구 삽입.

### ⑥ 입국심사 대화 가이드 (가장 인기 있을 섹션)
카드형으로 **질문 → 쉬운 답변** 구성. 영어 발음 한글 표기 병기.

| 심사관 질문 | 이렇게 답하세요 | 한글 발음 |
|---|---|---|
| What's the purpose of your visit? | Honeymoon. / Vacation. | 허니문 / 베케이션 |
| How long will you stay? | Seven days. | 세븐 데이즈 |
| Where will you stay? | (호텔명) in Honolulu. | |
| Do you have a return ticket? | Yes. | 예스 |
| Are you traveling together? | Yes, my wife/husband. | |

- 팁: ① 질문을 못 알아들으면 "Sorry, could you repeat?" ② **거짓·과장 금지**, 짧고 정확하게 ③ 휴대폰 사진(예약서) 바로 꺼낼 수 있게
- 금지 안내: "일하러(Work)"처럼 오해되는 표현 주의, 현지 결혼식·촬영 등 상업활동 있으면 사전 상담

### ⑦ 세관 신고 — 가져가도 되는 것 / 안 되는 것
| 구분 | 내용 |
|---|---|
| ❌ 대표 주의 품목 | 생과일·채소, 육류·육가공품(컵라면 스프 포함 주의), 씨앗·식물, 흙 |
| ⚠️ 신고 필요 | 현금 등 합산 **1만 달러 이상**, 고가 상품/선물, 상업용 샘플 |
| 💊 의약품 | 원래 포장 그대로, 처방약은 영문 처방/소견서 준비 |
| 🥃 주류·담배 | 성인 기준 면세 한도 초과 시 신고 |
| 🌺 하와이 | 하와이는 **농산물 검역이 더 엄격** (본토 이동 시 재검사) |

→ "애매하면 **신고(Declare)**" 가 원칙. 신고 후 문제 되는 경우는 드물고, 미신고 적발은 벌금 위험.

### ⑧ 허니문 상황별 팁 (차별화 포인트)
- 🏝 **하와이**: 직항 도착=호놀룰루에서 입국 → 이웃섬 이동 시 국내선 환승 (입국심사는 호놀룰루에서 1회)
- ✈️ **미국 경유 → 칸쿤 등 제3국**: **경유만 해도 ESTA 필요**, 연결편 시간 여유(환승 3시간 이상 권장)
- 🏝 **괌**: 괌 입국 규정도 ESTA 연동 여부 [확인 필요]
- 📸 웨딩드레스·턱시도·촬영장비: 상업촬영 오해 방지 → "personal use" 설명 준비
- 🎁 선물: 신혼부부 지인 선물·결혼 기념 상품 → 한도 내/신고 여부 확인

### ⑨ 이럴 땐 이렇게 (돌발상황 Q&A)
- 입국심사 줄이 너무 길어요 → 항공사 직원에게 연결편 시간 말하기
- 2차 심사(Secondary)로 안내받았어요 → 당황하지 말고 침착히, 공손히 답변, 여행사 비상연락처로 연락
- 짐이 안 나와요 → 수하물 분실신고(Baggage Service) 먼저, 보험 청구 서류 보관
- 연결편 놓쳤어요 → 항공사 카운터 → 재예약 요청
- ESTA 승인 거절 → 미국 비자 신청 안내(기간 오래 걸림, 출발 1~2개월 전 신청 권장)

### ⑩ FAQ (접이식 아코디언 10문항)
### ⑪ 비상 연락 & 상담 버튼
- [카카오톡 상담] [전화 상담] [내 여행 확인서 열기]
- 비상 연락처: 현지 비상연락처·주LA/주호놀룰루 대한민국 영사관 [확인 필요]

## 3. 화면(UI) 기획 — 현재 문제 → 수정 방법 → 기대 효과

| 현재 문제 (예상) | 수정 방법 | 기대 효과 |
|---|---|---|
| 글이 길면 고객이 이탈 | 카드·스텝퍼·아코디언 + 하단 고정 메뉴 | 필요한 정보까지 클릭 2~3회 |
| 입국 순서가 글로만 있으면 이해 어려움 | 7단계 **세로 타임라인 + 아이콘** | 한눈에 흐름 파악 |
| 영어 대화가 어려움 | 질문/답변 카드 + 한글 발음 + 복사·저장 버튼 | 공항에서 휴대폰으로 바로 확인 |
| 표가 모바일에서 깨짐 | 표 → **카드형 변환** (PC만 표) | 모바일 가독성 확보 |
| 경고 사항이 묻힘 | ⚠️ 빨간 점선 박스 (ESTA 사기 사이트, 신고 필수 항목) | 중요 정보 놓치지 않음 |
| 공항에서 인터넷 불안 | **PDF 저장 / 오프라인 캡처 버튼** | 데이터 로밍 없어도 확인 |

- 색상: 허니문 상품 페이지와 동일한 톤(아이보리/로즈골드/네이비 포인트)
- 고객 페이지 vs 관리자 화면 분리: 직원은 로그인 후 **편집/공개 토글**만 사용

## 4. 직원(관리자)용 기능 기획 — MVP → 2단계 → 장기

### MVP (1~2주)
- 정적 상세페이지 1개 (한국어)
- 상담 시 **링크 1개 발송**(카카오톡) → 반복 설명 삭제
- 내용 수정은 문서 한 곳에서 관리

### 2단계 (1~2개월)
- **지역별 입국 가이드 템플릿**(하와이/괌/미국경유) 자동 선택
- 예약 번호 입력하면 고객 이름·여정이 들어간 **개인화 안내서** 생성
- "읽음 확인" 표시 → 안 읽은 고객에게 출발 D-7 재안내
- 업데이트 이력(최종 확인일) 표시 + 만료 알림

### 장기 확장
- 국가별 입국 가이드(몰디브·발리·푸켓·유럽·호주) 확장 → **타 여행사 SaaS 판매 가능**
- 다국어(영어/일어), 출발 D-day 자동 알림톡
- 고객 질문 로그 누적 → FAQ 자동 개선 (데이터가 쌓일수록 가치↑)

## 5. DB 구조 제안 (Supabase — 엑셀 시트 비유)

| 테이블(엑셀 시트) | 역할 | 주요 항목(열) |
|---|---|---|
| `entry_guides` | 국가별 가이드 1건 (예: 미국) | 고유번호, 국가코드, 제목, 최종확인일, 공개여부 |
| `guide_sections` | 가이드 안의 섹션(준비/순서/세관…) | 가이드번호(연결고리), 순서, 섹션종류, 제목, 본문 |
| `guide_steps` | 입국 순서 단계 | 가이드번호, 단계번호, 장소, 할 일, 팁 |
| `guide_faq` | 자주 묻는 질문 | 가이드번호, 질문, 답변, 노출순서 |
| `guide_phrases` | 심사 질문/답변 문구 | 가이드번호, 질문, 답변, 한글발음 |
| `product_guide_link` | 상품(리조트·지역)과 가이드 연결 | 상품번호, 가이드번호 |

- **중복 방지**: 미국 가이드를 하와이·괌 상품마다 복사하지 않고 `product_guide_link`로 **연결만**
- **UPSERT**: 같은 가이드 재업로드 시 새 줄 추가 대신 기존 줄 갱신
- **안전한 삭제**: 삭제 대신 `공개여부=false` (고객 링크가 깨지지 않도록)
- **RLS 보안**: 고객 = 공개된 가이드 **읽기만** / 직원 = 로그인 후 수정 / 내부 메모는 별도 컬럼·테이블로 고객 조회 불가
- 기존 ERP·MASTER 화면과 충돌 없는지 → 상품 상세 화면의 "여행 안내" 탭에 **링크만 추가**하는 방식 권장 (데이터 구조 영향 최소)

2. 제가 **모바일 우선 HTML 상세페이지** 시안 제작 (고객용, 카드·스텝퍼·아코디언 포함)
3. 공식 사이트로 6번 항목 확인 후 숫자·조건 확정
4. 하와이 상품 상세페이지 "여행 안내 탭"에 링크 연결
5. 같은 구조로 괌 / 몰디브 / 발리 입국 가이드 확장
